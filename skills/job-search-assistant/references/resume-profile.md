# Resume and Profile Strategy

Use this for `/ai-job-search:resume`, `/ai-job-search:profile`, resume positioning, LinkedIn, JobStreet, Indeed, Foundit, Snaphunt, ATS profiles, portfolio text, headline, About, summary, experience bullets, and keyword strategy.

## Resume Rules

- Use resume/profile/source files as source of truth.
- If multiple resume versions exist, recommend the best matching version based on JD direction.
- If versions are unknown, say "best matching resume/version" instead of inventing filenames.
- Do not recommend tailoring before enough JD content exists.
- Keep ATS-friendly, natural, specific, and truthful.
- Add relevant JD keywords without exaggeration.
- Do not turn basic exposure into proficiency.
- Do not present assistant tasks, such as resume optimization or LinkedIn optimization, as the user's own job skill.

## Profile Rules

- LinkedIn: optimize branding, headline, About, experience, Featured, skills, and keywords.
- Job platforms: optimize ATS/search keywords, summary, work preferences, skills tags, salary expectation, and availability when user provides them.
- Portfolio: make projects easy for hiring managers to scan; connect proof to target roles.

When enough facts exist, provide copy-ready text.

## Copy-Ready Truthful Wording

Exposure-only skill:
- "Basic familiarity with SQL through coursework and practice projects."
- "Exposure to React in personal projects; strongest professional experience is in HTML, CSS, JavaScript, and CMS delivery."

Adjacent experience:
- "Built transferable experience in reporting, stakeholder coordination, and process improvement, now applying those skills to analyst roles."

Junior or school project:
- "Created a school project that simulated a client workflow."
- "Built a prototype for a real-world use case." Use "client" only if there was a real client.

Skill gap:
- "Currently strengthening Python through hands-on projects while bringing stronger experience in web delivery and analytics tools."

Authorization uncertainty:
- "Work authorization requirements vary by role and location; confirm eligibility and sponsorship expectations early."
