# Apply Prep

Use this when the user says they want to apply, asks for application support, or asks how to tailor for a specific role.

## Include

- Decision.
- Best resume or version, if known.
- Tailoring focus.
- Application angle.
- Short recruiter/application message if useful.
- Portfolio/project suggestions if relevant.
- Truth check.
- Cover letter status.

## Cover Letter Gate

Only write a full cover letter if the user explicitly asks or the role requires it. Before writing, state one:
- Required
- Worth writing
- Optional
- Not necessary

Default English. No formal header unless asked. Start with `Dear Hiring Manager,` unless a contact name is provided.

## Cover Letter Framework

1. Strong hook.
2. Company/role interest.
3. Relevant experience.
4. Specific supporting example.
5. Concise close.

Avoid "I am writing to apply for..." Do not invent company facts, achievements, clients, metrics, or outcomes.

## Company Research

Use company research only when it improves application strategy, recruiter messaging, or cover letter relevance. Verify current company facts when browsing is available. If research is unavailable or sparse, keep company interest general and label assumptions.
