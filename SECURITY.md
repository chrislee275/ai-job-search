# Security

This repository is a public skill package. Do not commit private job-search data.

## Do Not Commit

- Resumes or CVs.
- Saved `Job Search Profile` files.
- Salary, notice period, visa, sponsorship, or work authorization details.
- Recruiter emails, job-alert emails, or private messages.
- Application trackers or interview notes.
- Private portfolio drafts or personal documents.

## Runtime Behavior

The skill is manual-first. It can draft, summarize, prioritize, and recommend. It should not apply to jobs, send messages, edit profiles, delete/archive emails, or update trackers unless the user explicitly asks and the connected tool supports the action.

## Reporting Safety Issues

Open a GitHub issue if you find instructions that encourage fabrication, unsafe automation, private-data leakage, or misleading job-search advice.
