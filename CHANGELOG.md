# Changelog

## v1.0.0 - 2026-06-20

- Initial public release of `job-search-assistant`.
- Added 8 command-style workflows under `/ai-job-search:*`.
- Added Job Search Profile setup and refresh workflow.
- Added JD review, batch triage, apply prep, resume/profile strategy, recruiter reply, and interview prep references.
- Added optional automation-ready prompts with manual-first safety boundaries.
- Added examples and manual QA tests.
- Added public repository packaging: install/uninstall scripts, command/install docs, security policy, contribution guide, validation workflow, and lightweight repository validator.
- Added JD link access support for public pages through `scripts/extract_jd.py` plus browser-assisted review rules.
