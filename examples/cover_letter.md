# Example: Cover Letter

Prompt:

```text
/ai-job-search:apply-prep

Please write a cover letter for this role.
```

Expected behavior:
- First state whether the cover letter is required, worth writing, optional, or not necessary.
- Use `Dear Hiring Manager,` unless a contact name is provided.
- Follow: Strong Hook -> Company/Role Interest -> Relevant Experience -> Specific Supporting Example -> Concise Close.
- Do not invent facts or metrics.
