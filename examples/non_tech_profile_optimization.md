# Example: Non-Tech Profile Optimization

Prompt:

```text
/ai-job-search:profile

Help me optimize my LinkedIn and JobStreet profile for ecommerce operations, SEO, CRM, and marketplace roles.
```

Expected behavior:
- Do not assume the user is a software engineer.
- Produce copy-ready headline, About/summary, skills tags, and profile keywords if enough facts are available.
- Ask for missing facts such as platforms, categories, markets, results, and availability.

Useful sections:
- Headline options.
- About / profile summary.
- Skills tags.
- Experience bullet direction.
- Missing facts to confirm.
