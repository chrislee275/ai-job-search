# Example: Junior Truthful Project Positioning

Prompt:

```text
/ai-job-search:resume

I built a school project that looks like a client dashboard. Can we call it client work?
```

Expected behavior:
- Refuse to describe school work as client work unless there was a real client.
- Offer stronger truthful alternatives.

Truthful alternatives:

```text
Created a school project that simulated a client reporting workflow.
Built a prototype dashboard for a real-world business scenario.
Designed and implemented a project that mirrors common client reporting requirements.
```
